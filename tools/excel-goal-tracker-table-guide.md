# Excel 纯表格版：目标树与工作跟踪

这版不需要 VBA、宏或按钮，直接用 Excel 表格记录目标、举措、反馈和结果。

## 下载和打开

1. 打开仓库中的 `tools/excel-goal-tracker-table.csv`，下载文件。
2. 用 Excel 打开 CSV。如果中文显示异常，可在 Excel 中通过“数据 > 从文本/CSV”导入，并选择 UTF-8 编码。
3. 打开后选择数据区域，按 `Ctrl+T` 转成 Excel 表格，并勾选“表包含标题”。
4. 建议马上另存为 `.xlsx`，以后就用这个 Excel 文件更新。

## 怎么看树状关系

- 每一行是一项目标、举措或任务。
- “目标ID”要唯一；“上级目标ID”填它所属的父级 ID。总目标的上级 ID 留空。
- “层级”建议使用：1=总目标、2=阶段目标、3=举措、4=任务。
- 用“上级目标ID”筛选，或按层级和 ID 排序查看各级内容。CSV 是平面表格，不会自动画图，但这种结构便于筛选和跟踪。

示例关系：G001 总目标 → G002 阶段目标 → G003 举措 → G004 具体任务。

## 日常更新流程

1. **定目标**：填写目标内容和衡量标准，确保能判断是否达成。
2. **拆举措和任务**：每项都新增一行，填写自己的 ID 和上级目标 ID。
3. **安排责任和时间**：填写负责人、开始日期和截止日期。
4. **定期反馈**：更新进度、状态、反馈日期、最新反馈和下一步举措。
5. **完成后复盘**：把实际结果写清楚，与衡量标准对照。

## 列的含义

| 列名 | 用途 |
|---|---|
| 目标ID | 每条记录的唯一编号，如 G001、G002 |
| 上级目标ID | 该记录所归属的父目标 ID；总目标留空 |
| 层级、类型 | 用来区分总目标、阶段目标、举措和任务 |
| 目标/任务内容 | 清晰描述要实现或要完成的事情 |
| 衡量标准 | 定义怎样算完成或达标 |
| 负责人、开始日期、截止日期 | 安排责任和时间 |
| 进度%、状态 | 记录当前进展；状态可用未开始、进行中、已完成、延期、暂停 |
| 最新反馈日期、最新反馈 | 记录最近一次检查情况和障碍 |
| 下一步举措 | 明确接下来要做什么 |
| 实际结果 | 完成后填写事实结果，供复盘 |

## 初学者小建议

- 先只管理一个总目标，拆成 2–3 个阶段目标，再拆成可执行的小任务。
- 每周固定更新一次进度和反馈。
- 复制新行时记得换成新的目标 ID，并检查上级目标 ID。
- 可以用 Excel 的筛选器查看“进行中”或“延期”的事项；用条件格式给状态设置颜色。
- 示例数据可以改成你自己的工作内容，也可以删除示例行后从空白开始。

CSV 不保存 Excel 的格式、筛选设置或多个工作表；转存为 `.xlsx` 后，这些 Excel 功能就可以保存在工作簿中。
