# Excel 目标树与任务跟踪模板

这个模板帮助你在 Excel 中管理：

- 总目标
- 阶段目标
- 举措
- 具体任务
- 反馈更新
- 最终结果归档

适用场景：
- 个人工作规划
- 每日/每周任务管理
- 项目推进与复盘
- 目标拆解和执行跟踪

---

## 1. 适用说明

这个模板适合：
- 目标拆解
- 任务跟踪
- 进度管理
- 状态更新
- 结果复盘

建议每条任务都写清楚这几件事：
- 具体要做什么
- 目标是什么
- 负责人是谁
- 截止日期是什么
- 完成后如何证明成功
- 实际结果如何记录

---

## 2. Excel 中怎么使用

### 第一步：新建宏启用工作簿
请用 `.xlsm` 后缀保存工作簿，因为 VBA 宏需要启用宏。

### 第二步：打开 VBA 编辑器
按：
- Alt + F11

### 第三步：插入模块
在 VBA 编辑器里：
- 右键 VBAProject
- 选择 Insert
- 选择 Module

### 第四步：粘贴代码
把 `tools/excel-goal-tracker.bas` 的内容复制进去。

### 第五步：运行初始化函数
在 VBA 编辑器中，选择：
- `InitGoalTrackerSheet`

点击运行，Excel 会自动生成一个名为：
- `目标树`

的表格。

## 3. 主要功能说明

### 3.1 InitGoalTrackerSheet()
创建目标树工作表，自动生成表头：
- 目标ID
- 上级目标ID
- 层级
- 类型
- 内容
- 衡量标准
- 负责人
- 开始日期
- 截止日期
- 进度%
- 状态
- 最新反馈
- 下一步
- 实际结果

### 3.2 AddGoalTask()
新增一条任务或目标记录。
会询问：
- 目标ID
- 上级目标ID
- 层级
- 类型
- 内容
- 衡量标准
- 负责人
- 开始日期
- 截止日期
- 进度%
- 状态
- 反馈
- 下一步
- 实际结果

### 3.3 RefreshGoalColors()
根据状态自动填充颜色：
- 已完成：绿色
- 进行中：黄色
- 延期：红色
- 暂停：灰色
- 未开始：白色

### 3.4 BuildSummarySheet()
生成一个汇总表：
- 总条目
- 已完成
- 进行中
- 延期

## 4. 推荐使用方式

### 目标拆解结构
可以按下面这种结构写：

- 总目标：提升客户满意度
  - 阶段目标：缩短问题处理时间
    - 举措：建立常见问题库
      - 任务：收集问题
      - 任务：整理答案模板
    - 举措：改进跟踪机制
      - 任务：建立反馈记录表
      - 任务：每周检查进展

这样会更容易看清：
- 目标和举措是什么
- 任务有没有按时完成
- 中间反馈和调整是否有效
- 最终结果是否达标

## 6. 适合你的使用建议

如果你想长期用这个模板，推荐：
- 每周更新一次状态
- 每月复盘一次“实际结果”

- 一个目标不要写太大，最好不超过 3 层

## 7. 常见问题

### Q：为什么需要 `.xlsm`？
因为宏代码只能在启用宏的工作簿中运行。

### Q：我能直接在 Excel 里手工填写吗？
可以，表头和列都已经准备好了，完全可以手工填写。

### Q：是否需要编程基础？
不需要。你只需要会：
- 打开 VBA
- 粘贴代码
- 运行宏
